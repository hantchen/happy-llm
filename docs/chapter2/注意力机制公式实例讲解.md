# 注意力机制公式实例讲解

本文用一个具体的数值例子，拆解注意力机制核心公式的计算流程：从点积相似度、Softmax 权重、加权求和，到多 Query 矩阵形式，以及 $\sqrt{d_k}$ 缩放的作用。可与《第二章 Transformer架构》2.1.2 节对照阅读。

## 第一步：点积算相似度

假设词向量只有 2 维，含义是：

- 第 1 维：这个词的"食物"属性有多强
- 第 2 维：这个词的"家具"属性有多强

Query 是 "fruit"（水果），它的查询向量想找的正是"食物属性强、家具属性弱"的词：

$$q = (1, 0)$$

三个 Key 的词向量：

$$v_{apple} = (2, 1), \quad v_{banana} = (1, 0.5), \quad v_{chair} = (-0.5, 2)$$

逐个做点积（对应相乘再相加）：

- $q \cdot v_{apple} = 1\times2 + 0\times1 = 2$ —— 苹果食物属性强，得分高
- $q \cdot v_{banana} = 1\times1 + 0\times0.5 = 1$ —— 香蕉也不错
- $q \cdot v_{chair} = 1\times(-0.5) + 0\times2 = -0.5$ —— 椅子的食物属性是负的，方向相反

所以 $x = qK^T = (2,\ 1,\ -0.5)$。这个行向量就是 "fruit" 和每个词的相关程度，矩阵形式只是把这个循环写成了一次运算。

## 第二步：Softmax 变成权重

$$\text{softmax}(2, 1, -0.5) = \frac{(e^2, e^1, e^{-0.5})}{e^2 + e^1 + e^{-0.5}} = \frac{(7.39,\ 2.72,\ 0.61)}{10.71} \approx (0.69,\ 0.25,\ 0.06)$$

原始分数是任意大小的数（可以是负的、和不为 1），Softmax 做了两件事：指数化把负数变正、拉大差距；除以总和让三者加起来等于 1。于是它从"相关程度"变成了"注意力分配方案"：**69% 的注意力给 apple，25% 给 banana，6% 给 chair**。

## 第三步：加权求和得到输出

Value 向量代表每个词携带的"内容信息"。假设：

$$v_{apple} = (1, 0), \quad v_{banana} = (1, 0), \quad v_{chair} = (0, 1)$$

即 apple/banana 携带的是"水果类信息"，chair 携带的是"家具类信息"。

$$output = 0.69\times(1,0) + 0.25\times(1,0) + 0.06\times(0,1) = (0.94,\ 0.06)$$

输出向量几乎全是"水果类信息"——这就是注意力的本质效果：**带着 Query "fruit" 去句子里检索，把和水果相关的内容提取出来、拼成一个汇总向量**。椅子的信息几乎被过滤掉了。

> 正文中说"此时的值还是一个标量"，意思是：如果 Value 是数字，输出就是一个数；Value 是 $d_v$ 维向量（这里是 2 维），输出就是向量。

## 多个 Query 一起算

上面只查了一个 "fruit"。如果还有一个 Query "furniture"，就再把它的向量 $q_2$ 叠到 Q 里：

$$Q = \begin{pmatrix} q_{fruit} \\ q_{furniture} \end{pmatrix}, \quad attention(Q,K,V) = \text{softmax}(QK^T)V$$

矩阵乘法会并行完成两组查询，每一行是一次独立的"检索 + 加权汇总"。公式没变，只是批量了。

## 为什么除以 $\sqrt{d_k}$

Softmax 对分数的"尺度"非常敏感。看一组对比：

**分数较小 $(2, 1, 0)$ 时：**

$$\text{softmax} \approx (0.665,\ 0.245,\ 0.090)$$

权重有合理的梯度，第二名、第三名还有存在感。

**分数较大 $(20, 10, 0)$ 时：**

$$\text{softmax} \approx (1.000,\ 0.000045,\ 0)$$

第一名独吞全部权重，其他几乎为 0。

第一种分布训练时梯度健康；第二种叫"饱和"——权重几乎不变，反向传播的梯度趋近于 0，$W_q, W_k$ 学不动了。

而当 $d_k$ 很大时，点积恰好天然容易变大：$q \cdot k$ 是把 $d_k$ 个乘积加起来，假设每个分量是均值为 0、方差为 1 的随机数，点积的方差就是 $d_k$，标准差是 $\sqrt{d_k}$。比如 $d_k = 100$ 时，分数天然就是 ±10 以上的量级，Softmax 必然饱和。

除以 $\sqrt{d_k}$（上例就是除以 10），恰好把方差重新压回 1，让分数落回 Softmax 的"舒适区"。这就是缩放的作用：**不改变谁大谁小的排序，只调整差距的尺度，保护训练稳定性**。

## 总结

> 带着问题 $q$（"fruit"）去查一串词，用点积给每个词打分 $(2, 1, -0.5)$，Softmax 把分数变成百分比 $(69\%, 25\%, 6\%)$，再按这个比例把各词的内容混合起来——混合的结果就是"从这段文本中提取出的、与 fruit 相关的信息"。$d_k$ 大时分数会虚高，除以 $\sqrt{d_k}$ 防止 Softmax 极端化。
